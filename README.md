# Amigoscode Inspired REST API

Alas, it's been a couple of months since I've worked with Java, so I thought I would speed run through this tutorial
from Amigoscode. See his video from 2025 here: https://www.youtube.com/watch?v=Cw0J6jYJtzw

Amigoscode video is definitely a review of the basics, but I wanted to take it in another direction. Let's turn it into
a coffee boutique shop that is opening soon where the end user can request roasts and be contacted
when the blends are in stock. The end user can also ask a chatbot (ollama hosted model) what blend is best for them.
from ahe does go somewhere interesting here. At the end of the
tutorial, he creates this Java/SpringBoot API with PostgresQL and OpenAI integration. Personally, I'd rather use ollama,
and I'll use that here instead.
